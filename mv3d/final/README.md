# 《远去的列车》ALPHA · 最终版 MV

**一句话：外面是一场酒吧里的深夜演出；里面是一台机器的记忆。**

画面是 1920×1080，中间 2.39:1 的电影画幅（1920×804）。中英文歌词放在下方黑边里。帧率 24 fps，音频直接用整首母带。

## 视觉语言

- **现在（酒吧）**
  - 素材是用户提供的实物照片（becbd0 正面全身、14ea6d 侧面、6eb86e 近景、20ea29 正脸），用 IS-Net 抠出后重新打光：
    - 一盏暖色顶光打在脸和胸口，身体落进暗处；
    - 背后有冷色逆光束，雾中有尘埃。
  - 酒吧本身由代码搭建：砖墙、串灯、吊灯、酒架。
  - 台下观众剪影的头顶只到她的膝盖。按 3.5 m 身高的比例换算，这是这个镜头的尺度依据。
  - 镜头是缓慢的 2.5D 推拉。
- **记忆（素材）**
  - 用户的视频素材放在更小、更暖、更软的胶片片门里，带片门晃动、闪烁和灰尘。
  - 素材只有 480p，这本身成了语言：记忆永远没有现在清晰。
  - 素材里没有一个口型镜头，所有唱的镜头都在酒吧里，所以不存在口型对不上的问题。
- **机器内部（点云）**
  - 真实照片经 MiDaS 单目深度重建为三维点云，保持真实颜色，带景深。
  - 只在三处出现：记忆写入、被风吹散、像雪落下。

## 口型与动作（与实物同一套机构）

- **下颌：** 由机器人人声分轨（7 段）求包络；分轨没覆盖的句子，用母带 300–3500 Hz 人声频段逐句归一化补齐。
  - 再经过二阶舵机模型：7 Hz、阻尼 0.55、限速 140°/s、0° 硬限位。
  - 输出 0–9° 的下颌角。
  - 画面上，下唇和下巴作为一个刚体绕耳后铰点转动，张开处露出深色口腔和灰色支架。没有软嘴唇，没有牙齿。
- **头部：** 点头幅度跟随乐句和人声强度，侧倾是缓慢摆动。
- **眼睛：** 镜头眼的发光强度跟随人声（0.2–0.9）。

逐帧数值见 `out/final/motion_channels.csv`：

- 24 fps，整首歌；
- 列：`jaw_deg`、`head_pitch_deg`、`head_roll_deg`、`eye_glow_0to1`、`vocal_0to1`；
- 可以直接作为实物动画的关键帧来源。

`head_pitch` 和 `head_roll` 是建议幅度，可按实物舵机行程缩放。

## 文件

| 文件 | 内容 |
|---|---|
| `common.py` | 画幅、歌词、整首下颌曲线（`jaw_full.json` 缓存）、胶片调色 |
| `hero.py` | 酒吧镜头：抠像、刚性下颌、头部动作、灯光、观众、雾与光束 |
| `memory.py` | 记忆片门 |
| `pcloud.py` | 点云面孔与粒子记忆 |
| `spec.py` | 间奏的实物介绍 |
| `timeline.py` | EDL、并行渲染、合成、导出表格 |
| `ref_reel.py` | 动画参考片 |

渲染命令：

```
python3 timeline.py --workers 4      # 整片 → out/final/ALPHA_远去的列车_final_1080p.mp4
python3 timeline.py --still 18,37.9  # 单帧检查
python3 ref_reel.py                  # 动画参考片
```

渲染所需的模型和字体不在仓库里：

- `models/isnet-general-use.onnx`、`models/midas_small.onnx`；
- `fonts/` 下的 Noto CJK。

## 说明

- 没有调用任何付费生成，全部由代码和用户已有的照片、素材完成。
- 素材 B09 中有可读的牌子，这一段只用了 0–1.8 s 和 5.75–8 s，避开了那个镜头。
- B10 和旧 G00 不使用（比例问题）。
- 3.5 m 是影片中的身高。工作室照片是实物原图，画面上没有用标尺去“量”实物。
