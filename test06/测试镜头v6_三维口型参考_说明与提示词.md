# 测试镜头 v6：用三维机构模型驱动口型

## 做了什么

我按你的白模，用三维（three.js）搭了一个 ALPHA 头部的**机构模型**，嘴部的结构和动法与实体头一致：

| 部件 | 动不动 |
|---|---|
| 上唇、鼻子、颊板、额头 | 固定不动 |
| 下颌（下唇壳＋下巴竖条板） | 绕两侧铰链向下、向后转。**全嘴只有这一个转轴** |
| 口腔 | 黑色腔体，里面有两个金色减速电机和红色舵机，和你照片里一样 |
| 辅助动作 | 脖子一格一格地转（舵机式起停）；高音时眉毛链条微抬、眼睑微压；耳侧涡轮慢转 |

下颌的角度由歌声驱动，做法和真实的动画机器人（音频舵机板）一样：
1. 取人声频段的音量包络，过门限后换算成张开量。
2. 乘上每个字的开口大小（小、中、大，按韵母定）。
3. 再按舵机的物理特性处理：有速度上限，起步快，到位硬停带一点回弹，闭合时撞到机械限位会轻轻弹一下。
4. 最大张开 9°，这时上下唇之间的缝约等于上唇厚度。

**这个模型只负责“怎么动”，不负责“长什么样”。** 它的脸是简化的几何体，长相、颜色、材质仍然以角色卡为准。

## 如果结果不理想

- **成片变成了灰色或几何体的样子**：@视频1 换成上色版；或者去掉 @视频1，只用 @图片3 的状态卡。
- **口型还是会跑**：把 @音频1 去掉，只用 @视频1 驱动。三维动画里的口型已经和歌对齐，剪辑时我按母带对回去。
- **你的平台支持“动作参考／视频参考”强度的话**：先调到中等，太强会把三维模型的外观也一起抄进来。

## 这是一个通用工具

以后任何一句歌，都按同样的流程出口型参考，不用再一句一句写提示词：

1. 给我这句的人声（你分离出来的就行）。
2. 我跑一条命令：`rig/make_ref.sh 人声.wav 名字 [逐字表.csv]`。没有逐字表时，就只按音量驱动。
3. 得到三个机位的运动参考视频，和一个带声音的核对版。

工具的源码在仓库的 `rig/` 目录。等比例那一步，我会把同一个模型放进有人物参照的场景里，用来出比例和机位参考。
