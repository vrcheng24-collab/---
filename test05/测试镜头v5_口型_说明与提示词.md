## 我从白模里看到的结构

标注图见 `口部结构标注_给人看.jpg`。

| 部件 | 结构 | 唱歌时怎么动 |
|---|---|---|
| ① 上唇 | 一整块多面的硬壳，中间有人中凹口，两侧嘴角是尖的楔形，连在鼻子下方的面板上 | **不动** |
| ② 下唇＋下巴 | 下唇壳和下巴中间那块竖条板连成一体，组成下颌 | **整体绕两侧的铰链向下、向后转**。只有这一个动作，转动角度很小 |
| ③ 颊板 | 两颊各一块固定面板，下沿压在下颌外侧 | 不动。下颌转开时，从颊板下沿底下转出来 |
| ④ 口腔 | 下颌打开后露出黑色腔体，深处隐约能看到电机和舵机 | 没有牙齿，没有舌头 |
| 眼睛 | 透明镜头眼，上方是一层层叠起来的金属眼睑片 | 眼睑片可以微微下压或抬起 |
| 眉毛 | 一节一节的链条状金属条 | 高音时整条微微上抬，链节之间不变形 |

**物理上的限制：** 嘴只有一个自由度，就是下颌的开合角度。所以：
- 嘴宽不变，嘴角不动，上唇不动，嘴唇没法嘟起来或拉开。
- 字与字的区别只在**张开的大小和时间**：
  - a、e、o 这类开口音张得大；
  - i、u 这类闭口音张得小；
  - 换气时合上。
- 舵机的动法：**起步快，到位时硬停**，停住时有一点点回弹抖动。
- 长音时下颌**停住不动**，只带极细的颤。

## 这句歌的逐字开合

这是我从音频测出来的，误差约 0.1 秒。你分离出来的人声，起点和我切的片段一致就能用：0.5 秒开口。

| 秒 | 字 | 开合 |
|---|---|---|
| 0.5 | 真 | 中 |
| 1.0 | 心 | 小 |
| 1.4 | 的 | 小 |
| 1.75–2.4 | 人 | 中，2.4 秒换气时合上 |
| 2.6 | 又 | 中 |
| 3.05 | 能 | 中，3.6 秒短暂合上 |
| 3.9 | 有 | 中，4.6 秒短暂合上 |
| 4.8 | 几 | 小 |
| 5.2–6.0 | 个 | **大**，拖长音，下颌停在最大处 |
| 6.2 以后 | — | 合上，不再动 |

开合大小的标准：
- **小**：上下唇之间露出一条缝，约上唇厚度的三分之一；
- **中**：约上唇厚度的三分之二；
- **大**：约等于上唇的厚度。

最大也就这么大，**绝不能张成人类那样的大嘴**。

## 更好的办法：用真头拍一段动作参考

你有实体机器人头，下颌还是舵机驱动的。

用手机拍 5–10 秒：
- 让下颌按这句歌的节奏一开一合（用程序驱动，或者手动掰都行）；
- 机位用四分之三侧面，背景尽量干净；
- 关掉声音。

然后作为 **@视频1** 上传，提示词里加一句：“口部的运动方式和幅度参考 @视频1”。真实机械的动作比任何文字描述都准，模型照着动，就不会再长出人类的嘴。

如果能做到，再拍三张静态照：闭合、半开、全开，作为口型状态参考。
