# CG 头部 v1（Blender / Cycles）

## 这一版做到了什么

- **渲染器**：从 three.js 换成了 Blender 的 Cycles，有真实的金属反射、镀层车漆、玻璃折射、景深和电影色彩管理。
- **脸**：按你白模的面板分缝画好缝线，从一张完整的脸部曲面上切出各块面板。面板贴合脸型，缝隙均匀，每块都有厚度和倒角。
- **嘴**：
  - 上唇、鼻子、颊板固定；
  - 只有下颌（下唇加下巴三块板）绕铰链转动，两根活塞跟着下颌伸缩；
  - 口腔里是金色减速电机和红色舵机。
- **眼睛**：
  - 玻璃镜头、发蓝光的虹膜、8 片光圈叶片（会随情绪收放）、镜头圈；
  - 上眼睑 3 层、下眼睑 2 层快门片；
  - 13 节链条眉毛，内侧和外侧可以分开抬。
- **表情**：中性、深情（眉内侧上抬、眼睑半垂、虹膜收小）、高音（眉毛上扬、眼睛睁开）、收尾（眼睑慢慢合下）。
- **动作**：下颌按歌声驱动；脖子一格一格地转；高音时切换到高音表情；唱完低头，眼睑合下。

## 和“变形金刚影视级”的差距（实话）

这个头是我用程序从零搭的，**属于预演（previs）级别**：
- 结构和动法是对的，可以作为口型和表情的运动参考；
- 但细节密度、头盔的造型、侧面和后脑的机械结构，都远达不到电影资产的标准。

电影级的硬表面模型，通常是建模师照着设计逐块建几个星期才完成的。

## 要达到影视级，最快的路

**你的白模是 3D 打印的，所以一定有三维文件。** 请把头部（最好连身体）的模型文件发我，格式可以是 STL、OBJ、STEP、FBX 或 3MF，分件的最好，比如下颌、上唇、眼睑、眉毛各是单独的零件。

有了真实的模型，我可以：
1. 导入 Blender，**按真实零件和真实转轴**绑定下颌、眼睑、眉毛、光圈和涡轮。动作就是实物的动作，不再是我的近似。
2. 套上和完成品一致的材质：银色拉丝金属、黄色和青色车漆、玻璃眼、磨损和划痕。
3. 用电影灯光渲染特写、全身，以及有人物做参照的巨大比例镜头。
4. 这套资产可以反复使用：每一句歌、每一个表情、每一个机位，都能直接出参考视频，也能直接作为成片的特写镜头。

如果没有分件模型，次一级的办法是**对完成品做三维扫描**。手机上的扫描 App 或摄影测量都可以，我负责重新拓扑和绑定，但精度和可动部件都不如原始模型。
