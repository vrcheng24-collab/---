# 测试镜头：演播室·“真心的人又能有几个”

> 用来检验三件事：**关键帧＋素材卡能不能锁住 ALPHA 的脸和吉他**、**音频参考能不能对上金属嘴唇的口型**、**机器人式的深情动作出不出得来**。
> 这一镜就是 G04 的第 1 镜，测试通过后可以直接剪进成片。

## 设置

| 项目 | 填写 |
|---|---|
| 模型 | Seedance 2.0（单镜头，15 秒以内） |
| 时长 | 8 秒 |
| 比例 | 21:9，分辨率选最高 |
| @图片1 | **K20 NEW**：`008_K20_S02_面部与吉他极近景_NEW_成熟造型候选.png`（MAT-002）— **首帧** |
| @图片2 | **角色卡**：`角色卡.PNG`（MAT-035）— 锁脸和机身 |
| @图片3 | **新吉他卡**：`新吉他卡.PNG`（MAT-034）— 锁黄色电吉他 |
| @音频1 | `测试_真心的人_8s.mp3`（或同名 .wav） |

## 音频

- 截自母带 60.70–67.70 秒，最后补 1 秒静音，共 8.00 秒。
- 歌词“真心的人又能有几个”：约 **0.5 秒开口，6.2 秒唱完**。前后都切在实测的换气处，没有切到字。
- 6.2 秒以后只剩伴奏尾音，7 秒以后是静音。

## 看结果时检查

1. 脸是不是角色卡那张银色分片脸；吉他是不是新吉他卡那把（黄色、银色齿轮轮毂）。
2. 口型：0.5 秒开口，6.2 秒闭口，中间不乱动。
3. 头部转动是不是一格一格的，涡轮转了没有，虹膜有没有收放。
4. 有没有长出牙齿、舌头或人类皮肤。

**结果发我。** 如果口型对不上，下一版把“分段转头”去掉，只保留嘴和虹膜的动作，先确认口型能对上。
