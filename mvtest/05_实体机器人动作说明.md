# 实体机器人动作表：说明（v0 草稿）

`05_实体机器人动作表_v0.csv` 是按成片时间线排的逐帧动作，每秒 25 帧，从冷开场到收工，共 6911 帧。它的用途有两个：
- 让 AI 生成的演出和真机能做到的动作保持一致；
- 交给你们的机器人团队编程，让真机复现 MV 里的演出。

## 各列含义

| 列 | 单位 | 现在怎么算的 |
|---|---|---|
| `frame_25fps`、`mv_time_s`、`song_time_s` | 帧 / 秒 | 成片时间从 0 开始；歌曲在第 12 秒进 |
| `section` | — | 冷开场、前奏、A1、B1、C1、间奏、A2、B2、C2、尾段、尾奏、掌声／收工 |
| `jaw_deg` | 度，0–9 | 由人声频段的音量驱动，再按舵机特性处理：有速度上限，起步快、到位硬停、带一点回弹；只在有歌词的时段张嘴 |
| `neck_yaw_deg` | 度 | 每句开头转向一侧，左右交替，幅度 4°–8°；速度限制在每秒 40° |
| `neck_pitch_deg` | 度 | 高潮 C2 段抬头 8°，尾段低头 6°，冷开场先低头再抬起，收工时低头 |
| `upper_lid_pct` | 0＝全开，100＝全闭 | 按段落的情绪：深情 35，高潮 10，收尾 60 |
| `brow_inner`、`brow_outer` | 0–1 | 深情时内侧抬，高潮时整条抬 |
| `iris_open_pct` | % | 深情时收到 55，高潮时开到 95 |
| `right_arm_strum` | 0/1 | 歌曲中扫弦；尾段第 217.8–224.3 秒停下 |
| `finger_tap` | 0/1 | 同一时段，两根手指在琴身上敲拍子 |

这首歌约每分钟 70 拍（我从母带估算的），扫弦可以跟拍子走。

## 注意

1. **这是草稿。** 下颌现在是从母带算的，母带里有伴奏，会有误差。拿到你的人声分轨后，我用干净的人声重算，误差会小很多。
2. **通道和范围要对上真机。** 拿到规格确认表后，我把每一列换算成你们舵机的实际角度和方向，超出范围的地方会截断。
3. **现场演出时，下颌最好用音频实时驱动。** 让控制板直接听人声分轨，跟这张表的算法一样：取音量、过门限，再限速。这样就算音乐和动作有一点不同步，嘴也永远对得上。
4. **其他通道按这张表回放就行。** 脖子、眼睑、眉毛、光圈、手臂这些动作慢，误差几帧看不出来。
