# 测试镜头 v2：演播室·“真心的人又能有几个”

## 上一版的问题和这次的改法

| 你看到的问题 | 原因 | 这次怎么改 |
|---|---|---|
| 嘴型像人类的软嘴唇 | 提示词只写了“金属分片”，角色卡上又是一对饱满的青色嘴唇，模型照着角色卡画成了软唇 | 把嘴改写成一套**硬金属口器**：两片唇甲加两侧颚片，沿铰链一格一格地开合，像变形金刚说话、像蜻蜓的口器。写明嘴部结构以文字为准，角色卡只管颜色 |
| 人物锁不住，每个镜头光感不同 | 一组里传了 4–5 张关键帧，每张都当成了首帧或构图来抄，光线跟着各自的图走 | **以素材卡为主**：角色卡锁人，吉他卡锁琴。**只留一张关键帧，而且只当光影参考**，写明不抄构图、不当首帧 |
| 画面有 3D 玩具感，不像实拍 | 全身正面、居中、对称，光线平 | 写明**手持纪实跟拍**、胶片颗粒、单一顶光侧逆光、跑焦和呼吸感晃动；禁止 CG、塑料光泽、证件照式对称构图 |

我查的 Seedance 2.0 / 2.5 提示词经验，和你说的一致：
- 每个素材都要写清楚它管什么（人物、道具、光影、首帧），没写清楚的参考最容易出问题。
- 人物一致性靠同一张角色参考反复用，**两三张清楚的参考比五张杂的好**。
- 首帧只在必须固定构图时才用。
- 2.5 读的是整句的导演描述，不是关键词堆砌；长片段按时间段写节拍。

**关于“人声突出版”：** 它只是把中置声道和人声频段提出来、压低了两边的伴奏，**不是干净的人声**，伴奏还在。资料里说对口型最好用干声；你的平台如果有人声分离功能，分离后的人声效果会更好。

## 提示词（整段复制）

```
人物形象参考 @图片1（ALPHA 的脸、头部黄色翼片、青黄银三色机身），她抱着的电吉他参考 @图片2；@图片3 只作为光影、色调和胶片质感的参考，不要复制它的构图和人物姿势。@音频1 是她的演唱。

一部写实电影里的纪实镜头：黑色演播室，只有一盏暖色顶光从她左后上方打下来，在金属外壳上留下硬朗的高光和深阴影；薄烟里，背景暗处是虚焦的观众剪影和一架铝梯。35mm 胶片颗粒，轻微光晕，暗部偏青绿，高光偏暖黄，低饱和。手持摄影机跟拍，有轻微的呼吸感晃动，焦点在她的眼睛和嘴之间轻轻游移；镜头从侧前方的中近景，极慢地推到面部特写。

ALPHA 是一位成年女性机器人，身上没有任何人类皮肤。她的嘴是一套硬金属口器，不是人类的嘴唇：上下两片青色金属唇甲，两侧各有一片可以开合的金属颚片，连着铰链和细小的伺服活塞，像变形金刚说话时的机械嘴，也像蜻蜓的口器。唱歌时，颚片沿着铰链向两侧和下方一格一格地打开、合上，唇甲整体平移，金属本身不弯曲、不变形、不拉伸；张开时里面是黑色的机械腔体和一排微微发光的发声格栅，没有牙齿，没有舌头。

0–0.5 秒：她低着头，金属手指按在琴弦上，口器紧闭。
0.5–6.2 秒：她唱「真心的人又能有几个」，口器的开合与 @音频1 的每个字对齐；头部按小角度一格一格地偏向一侧，每格之间停一下，像在人群里找一个人；唱到长音时耳侧涡轮慢慢旋转；蓝紫色虹膜像相机光圈一样慢慢收小。
6.2–8 秒：歌声停了，口器一格一格地合上；她停在偏头的位置，虹膜重新张开，按弦的手指有伺服电机般的细微颤动。

动作是机器的，情绪是真的。声音以 @音频1 为准，不要另加背景音乐。
不要：3D 渲染、CG 玩具感、塑料光泽、正面居中对称的证件照构图；柔软的人类嘴唇、嘴唇变形或拉伸；牙齿、舌头、人类皮肤；字幕和文字；慢动作、转场、切镜。
```

## 看结果时检查

1. **嘴**：是不是硬金属口器沿铰链开合，有没有出现软嘴唇。
2. **人和琴**：是不是角色卡和吉他卡的样子。
3. **光和质感**：是不是只有一盏顶光，有没有胶片颗粒和手持晃动，像实拍还是像 3D。
4. **口型时间**：0.5 秒开口，6.2 秒闭口。

## 你那条 28 秒（G01）里，我还看到这几处

- **手部特写**用的 MAT-033，手是黑色的，和她的银青色机身对不上。以后手部镜头也只用角色卡，不传这张。
- **全景**是全身正面居中，最像 3D。以后全景写侧面或背侧，人物不放正中。
- **胸口散热缝特写**拍成了胸部特写，很尴尬。以后改成脖子侧面或锁骨处的散热缝。
- **反应镜头**里老杨坐在林姐旁边，位置不对，他应该在梯子上。以后老杨和林姐分成两个镜头写。
- **好的地方**：林姐和老杨的长相、气质都很对。可以从这一帧截图，当以后的人物参考。

这一版的嘴型和光感确认可以以后，我按同样的规则把 16 组提示词全部改一遍：以素材卡为主，每组只留一张关键帧，而且只当光影参考；首帧只在 K22 开场和 R03 原图这种必须照抄构图的地方用。
