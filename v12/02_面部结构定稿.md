# 02　面部结构定稿

身体可以换，脸不能换。初代机体、低谷期戴假发的她、3.5 米的舞台机体，用的都是**同一张脸**。观众靠这张脸认出她。

## 零件：哪些固定，哪些会动

| 编号 | 零件 | 状态 |
|---|---|---|
| 1 | 黄色头盔、V 形额饰 | 固定 |
| 2 | 额中传感板 | 固定 |
| 3 | 青色眉条（链节式） | **动**：内侧抬起表示难过、怀念；整条抬起表示唱高音、惊喜 |
| 4 | 镜头眼（蓝紫虹膜、金属光圈叶片） | **动**：光圈收小表示专注、克制；张开表示释然、被打动 |
| 5 | 叠层眼睑快门片 | **动**：一层层落下表示低落、温柔；收起表示认真、振作。眨眼也是快门片落下再收回 |
| 6 | 鼻梁和螺丝 | 固定 |
| 7 | 裂纹拼接的银色面板 | 固定，永远不弯曲、不变形 |
| 8 | 上唇（青色硬壳） | 固定 |
| 9 | 下颌（下唇和下巴一整块） | **动**：绕耳下铰链转开、合上 |
| 10 | 嘴角小板 | **动**：微微上扬是机械的笑，下压是忍住 |
| 11 | 颊侧黄色格栅 | 固定 |
| 12 | 耳侧涡轮 | **动**：激动时转快，平静时转慢 |

## 嘴：只有三种状态

| 状态 | 什么时候用 |
|---|---|
| 闭合 | 不唱的时候、换气的时候、第一个字出声之前 |
| 小开 | 正常演唱，这是上限 |
| 最大张开 | **只用于全片的最高音**（G12 开头） |

嘴里是深色的机械腔：上沿一排灰色金属支架，下面是连杆，**没有牙齿和舌头**。嘴唇是硬壳，不变软、不噘、不变圆。

> 提醒：彩色状态卡“最大张开”那一格的嘴偏圆，里面那排灰色支架在小图上有一点像牙齿。所以我把最大张开限制在最高音那一下。如果回片里出现了牙齿，下一条就把状态卡换成只有“闭合”和“小开”两格的裁切版，或者干脆不传状态卡。

## 深情怎么演：每个段落用哪些零件

| 段落 | 情绪 | 零件 |
|---|---|---|
| A（思念） | 克制 | 眼睑半垂，目光慢慢移远，光圈收小，蓝光变暗 |
| B（怀念） | 寻找 | 眉条内侧上抬，目光在人群里移动，光圈随乐句收放 |
| C（释然） | 温暖 | 眼睑收起，光圈张开，嘴角小板上扬，涡轮转快 |
| 尾段 | 告别 | 头慢慢低下，手越弹越慢，眼睑一层层落下，最后光圈重新张开 |

**规则：** 注意力先到眼睛，再到头，最后到身体。表情只来自零件，面板本身永远不变形。

## 回片时我会检查的“脸”

1. 裂纹面板的走向、鼻梁、V 形额饰、颊侧格栅是否和 `面部定妆.jpg` 一致；
2. 嘴有没有超出三种状态，有没有牙齿、舌头、软嘴唇；
3. 初代机体的脸是否和现在是同一张脸（只有饰条换成银色）；
4. 表情是不是来自零件（眉条、眼睑、光圈、嘴角小板），而不是面板在变形。
