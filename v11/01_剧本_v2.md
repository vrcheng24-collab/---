# 01　剧本 v2：《远去的列车》

## 一句话

一台会唱歌的机器人，被人嫌弃的时候很小，被人追捧的时候很大。她唱的始终是同一首歌。

## 这一版改了什么

| 改动 | 内容 | 为什么 |
|---|---|---|
| **新增 G11B「蜕变」** | 她从 1.7 米的初代机体被改装成 3.5 米的舞台机体 | 交代“她为什么变得巨大”。回忆里的小、现在的大，从此成了故事的一部分，而不是设定上的矛盾 |
| **暗讽“人们喜欢新的”** | 改装是市场部的主意：“观众不在乎她唱什么，观众要新的”。发布会上，当年拔她插头的保安、赶她走的面馆老板、说她“没有生命”的专家，都在举着手机给她拍照、背对她自拍。她唱的还是那首没人听过的歌 | 人们追的是“更大、更新”，不是她；真正听她唱歌的，还是人群最后面那三个没举手机的朋友 |
| **一个贯穿的小物件：黄色糖纸** | 老周给她的润喉糖（G05）→ 改装时工人把旧机体手心里的糖纸丢进垃圾桶，3.5 米的她弯腰用两根手指把它捏回来（G11B） | 身体全换了，她还是她。这是“她是活的”最直接的证据 |
| **她是活的** | 每个镜头都写了她在注意谁、想什么、怎么回应；动作是“先眼睛，再头，再身体”；身边的人看她、等她、和她配合 | 导演反馈：她不能像被搬运的装置 |
| **去掉钢制底座** | 现在的她靠**脚跟的轮子**滑行（三视图里本来就有），背后拖一根供电线缆，不迈步 | 让她自己进场、自己停下、自己回应；3.5 米和“不迈步”的设定都不变 |
| **中国人物和中国语境** | 所有人物都是中国人；场景具体到电视台演播室、北方小站和绿皮火车、老小区、KTV、劳务市场、地下通道 | 导演反馈 |
| **呼应的节拍** | 老周在养老院的扶手上敲拍子（G13）↔ 她在演播室的琴身上敲同样的拍子（G12）↔ 结尾两人在长椅扶手上一起敲（G15） | 老周忘了她，但他的手指还记得那首歌 |
| **结尾** | 3.5 米的她在长椅边**单膝跪下**，头仍然比老周高；老人像对陌生人一样问她的名字 | 全片唯一一次弯腿，留给老周。这个动作真机需要专门的跪姿机构，见“实体机器人”一节 |

## 故事（按时间顺序）

1. **诞生**（G02）：老周在旧实验室里给她开机，教她按和弦，带她去商场唱歌。一个小女孩碰了碰她的手指，她把手翻过来递给小女孩，女孩的母亲说：“别碰，那是个东西。”
2. **被否定**（G03）：人们举着手机笑她；听证会上，专家说“它的悲伤只是一段程序”；AI 音乐广告下，真人乐手也失了业。
3. **照顾与报废**（G05）：老周开始忘事，钥匙放进冰箱，在手背上写字。他把一颗黄色糖纸的润喉糖放进她手心。一纸通知下来，她被盖上篷布丢进仓库，蓝光熄灭；老周深夜打着手电把她找回来。
4. **告别**（G06–G07）：老周要去养老院了。在站台上，他给她披上羽绒服、围上自己的围巾：“去唱吧，别在仓库里等我。”火车开走，她在站台站了七个小时，然后第一次自己弹唱这首歌。
5. **低谷**（G08–G09）：她戴着廉价假发混在人群里讨生活：劳务市场、拆解厂、冷库、黑市充电、红灯房间、KTV 卖唱。在 KTV 里，只有一个穿黑夹克的年轻人在听，他叫阿凯。
6. **同类**（G10–G11）：地下通道里，保安拔了她的插头。小鹿给她接上电，说：“我们也是。”她摘下假发。在雨夜的天台上，四个人一起唱，对面楼的窗户一扇扇亮起来。
7. **蜕变**（G11B，新增）：天台的视频火了。市场部把她改装成 3.5 米的舞台机体：“观众要新的。”旧身体被盖上篷布，她弯腰从垃圾桶里捏回那张糖纸。发布会上，手机的海在欢呼，当年冷眼看她的人都在里面。她在人群最后面找到了那三个没举手机的朋友。
8. **现在**（G00、G01、G04、G12、G14）：电视台演播室。主持人林姐问她：“你的悲伤，是真的吗？”她问：“我可以唱出来吗？”她唱完，全场起立。她回答：“我不知道它算不算真的。他走的那天，我在站台站了七个小时。”
9. **之后**（G13、G15）：冬夜的养老院里，老周已经不认得她了，手指却跟着她的歌敲拍子。春天，她坐着平板货车回到那个小站，在长椅边单膝跪下。老人问她叫什么名字。“ALPHA。”“阿尔法……好名字。像是第一个。”

## 实体机器人（给机器人团队）

这一版对真机的要求有三处变化：
1. **脚跟轮驱动**：用来滑行进场、停下、小幅转身。腿不迈步。
2. **腰部回转和上身前倾**：用来回应人、鞠躬、弯腰。G11B 里弯腰从垃圾桶捏糖纸，是前倾幅度最大的一次。
3. **单膝跪下**（只用于 G15）：如果真机做不到，就改成她站在长椅边，把手掌放低到老周身旁，后者对真机更容易实现。正式动作表出来时，我会把这两种做法都列进去。
