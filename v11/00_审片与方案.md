# 00　G00 首镜审片与修改方案（回复导演反馈）

## 1. 为什么她像一台被搬运的装置

我看了原片和抽帧。画面质感、演播室的光和烟、人和她的比例（人大约到她的腰胯）都是对的。问题出在**表演**，而且主要是提示词造成的：

| 现象（原片里能看到的） | 原因 |
|---|---|
| 4 秒里她完全不动：低着头，眼睛不亮，只跟着底座平移 | 提示词原话就是“低着头，眼睛不亮……本体随底座一起平移进场”，模型照做了 |
| 所有的动作都来自推车的人，她是被推的“货” | 主动方是工作人员，她的唯一动作是“被推” |
| 没有一个人看她，大家都看着底座和地面 | 没写人和她之间的视线和交流 |
| 机位远、她的脸在画面上方很小，看不清眼睛 | 一个全景里，观众读不到她在想什么 |
| 设定段落全是“不能”：不走动、腿不动、最多 10 度、比人慢 | 只写了限制，没写她**想要什么**，模型就把她当成了道具 |
| 工作人员不像中国人 | 没有写明中国人物和中国语境 |

## 2. 推荐方案：她自己进场，并和人互动

**关于底座：** 我建议**去掉“被人推的钢制底座”**。角色卡（三视图）的侧面和背面，她的脚跟里本来就有**轮子**。所以她可以**自己滑行进场**：不迈步，脚不动，靠轮子移动。

- **身高 3.5 米、不迈步走路，这两条设定都不变。**
- 改掉的只是我上一版自己加的“固定钢制底座、由人推入”。这本来不是导演的设定，而且正是它让她显得像货物。
- 背后保留一根粗供电线缆，由场务一路理线。这样既有实体机器人的真实感，也给了工作人员和她互动的理由。
- 如果导演仍然想保留底座，备选方案是**电动底座，由她自己操控**，人只在旁边引导。

**首镜动作（4 秒，一个完整的反应过程）：**

| 时间 | 她 | 工作人员 |
|---|---|---|
| 0–1.2 秒 | 已经在滑行进场，眼睛亮着；光圈对准前方倒退着走的场务主管 | 主管倒退着走，抬手引导；两个场务在旁边小跑理线，抬头看她 |
| 1.2–2.5 秒 | 主管握拳示意“停”，她的目光落到他的手上，减速、停稳 | 主管停住，抬头等她的反应 |
| 2.5–4 秒 | 她向主管轻轻点一下头，眼睑快门片收起，像在说“我准备好了” | 主管笑了一下，竖起大拇指；理线的场务也停下来抬头看她 |

**注意力先到眼睛，再到头，最后到身体。** 这条规则放进了每一组的提示词。

## 4. 中国人物和中国语境

我在**每一组**的提示词里都加了一段固定说明：所有人物都是中国人，场景是当代中国的具体地方（电视台演播室、北方小站和绿皮火车、老小区、城中村、KTV、劳务市场、地下通道）。MJ 提示词里也给每个人物写了中国人的外貌（老周、林姐、老杨、小鹿、阿凯、默默、场务、市场经理）。旧图里人物不像中国人的几张，比如天台合奏，已经列为“必出”或“建议重出”。
