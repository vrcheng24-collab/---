# 刚性下颌诊断片：复核结果与下一步

> 复核对象：`01_刚性下颌_有声原片.mp4`、`02_test2.mp3`、状态卡、执行提示词。
> 方法：逐帧测量嘴部区域的张开程度（每秒 24 帧），并把成片音轨和 test2.mp3 的音量包络对齐比较。我没有逐字听写歌词，下面凡是涉及“哪个字”的地方，都只按音量起伏判断。

## 1. 机械开合：哪些达标，哪些不达标

**测量结果（成片时间）**

| 时间 | 下颌状态 |
|---|---|
| 0–2.6 秒 | 闭合 |
| 2.75–4.5 秒 | **一次大开，并一直停住** |
| 4.6–5.5 秒 | 闭合 |
| 5.6–7.0 秒 | **第二次大开，并一直停住** |
| 7.1–8 秒 | 闭合 |

全片只开合了两次。test2.mp3 里大约有 9–11 个音节起点（第 0.47、1.03、1.42、2.25、2.62、3.39、3.81、4.56、4.82、5.25、5.80 秒），中间有两处换气停顿（约 2.5 秒和 4.75 秒）。

**达标的部分**
- 下颌是一整块刚性零件，绕铰链向下、向后转，看得到机械内腔和侧面接缝。
- 没有软嘴唇、噘嘴、圆口和舌头。
- 头部基本固定。
- 开合有起停感，像舵机。

**不达标的部分**
1. **没有逐字开合。** 只有两段长时间张开，跟音节对不上。这是最主要的问题。
2. **张开幅度远超上限。** 2.75 秒以后，下巴落到接近整个下半张脸，远大于状态卡第 3 格。
3. **结构变了。** 第一次张开以后，耳侧那块长条护板消失了，脸颊侧面也变了，之后再没恢复（见 `本轮问题截图.jpg`）。
4. **机位不对。** 拍成了接近正侧面，和状态卡的四分之三侧不一致。这也是结构容易跑的原因之一。

**用测量脚本复核**（`tools/mouth_check.py`，以后每条回片都用它测）：
```
audio offset: clip soundtrack = reference shifted by +1.45 s
open/close cycles: 2
syllable onsets in reference: 11
jaw opening starts: [2.75, 5.62]
```

## 2. 声音和下颌：分开诊断

**确定的事实**
- 成片音轨就是 test2.mp3 整体往后推了约 **1.45–1.5 秒**：两者每 0.25 秒的音量序列，错开 6 格以后几乎一一对上。所以成片开头约 1.5 秒是静音，结尾截掉了 test2 最后一点尾音。
- 下颌第一次张开在 2.75 秒，比成片里歌声出现（约 2.0 秒）晚了约 0.75 秒。

**推测（尚未证实）**
- 两段张开大致对应歌声的两大块，但开合的位置和 test2 的两处换气停顿也对不上。所以模型很可能只是“知道有人在唱”，并没有逐字驱动下颌。

**这条能不能靠剪辑救回来？**
- **声音偏移可以修正。** 偏移是一个固定值，剪辑时按成片音轨和人声分轨做一次对齐就能消掉。以后我会自动测这个偏移，所以**生成声音保持开着反而有用**，它就是对齐的标尺。
- **口型救不回来。** 画面里本来就没有逐字开合，怎么平移都对不上字。这条不能当对口型镜头用。
- **可以留作素材。** 其中 2.75–4.5 秒那段持续张开、能看清机械内腔，可以放进间奏的“机械细节”镜头（P5），前提是不需要对口型。但它张开幅度超标，放进成片前要你确认能不能接受。

## 3. 只推荐一个下一步

### 一条 8 秒的定向测试

预算 40 积分以内，Seedance 2.0 标准版，480p，21:9，生成声音开启。

**这次改什么，为什么改**

| 改动 | 针对哪个问题 |
|---|---|
| 加首帧 `首帧_闭合_21比9.jpg`（状态卡第 1 格补成 21:9，背景同色） | 机位跑成正侧面、侧护板消失 |
| 状态卡仍然上传，作为幅度上限 | 张得太大 |
| 提示词改成“数次数”：这段歌有 9–11 个字，下颌必须开合同样多次，每个字之后都要回落 | 只开两次、长时间停住 |
| 用具体的比较物写上限：最大张开时上下唇的缝不超过上唇的厚度，下巴尖下移不超过鼻子长度的一半 | 张得太大 |
| 写明耳侧护板、颊板、眼眉在每一帧都保持原样 | 结构变化 |
| 要求声音从视频第 0 帧开始，不加前置静音 | 1.5 秒偏移（能修好最好，修不好也不影响） |

**不变的部分**
- 同一个 test2.mp3；
- 白模外观；
- 固定头部、固定眼眉（仍然是单变量诊断）；
- 8 秒，480p。

**提示词（整段复制）**

上传顺序：@图片1 `首帧_闭合_21比9.jpg`，@图片2 `03_实际绑定_状态卡_上传用.jpg`，@音频1 `test2.mp3`。

```
@图片1 作为首帧：严格保持它的机位（正面偏四分之三的头部特写）、构图、光线和每一个零件；整条视频机位固定，头部固定不动。@图片2 是这个机械头部嘴部的合法状态：上排从左到右是闭合、小开、最大张开，下颌任何时候都不能超过上排第3格的开口。@音频1 是这条视频的歌声：声音从视频第0帧开始，按原样播放，不要在开头加静音，不新增台词或配乐。

这是一台实体机械头部在执行下颌舵机程序。只有一个零件在动：下唇和下巴连成的整块刚性下颌，绕两侧同一根铰链轴向下、向后转开，再转回闭合。上唇、鼻子、颊板、耳侧长条护板、耳侧涡轮、眉毛、眼睑和眼球，在每一帧都和首帧完全一样，不移动、不消失、不变形。
开口上限：最大张开时，上下唇之间的缝隙不超过上唇本身的厚度，下巴尖向下移动的距离不超过鼻子长度的一半。
逐字开合：这段歌声大约有 10 个字。每唱一个字，下颌就快速转开一次，字的元音结束时立刻回落到闭合或接近闭合，然后再为下一个字转开。整段至少开合 8 次，绝不能长时间张着不动；只有最后一个拖长的字可以停在张开位置，直到它结束再闭合。字与字之间的换气停顿处，下颌完全闭合。开合像舵机：起步快、到位硬停、带一点点回弹。歌声结束后完全闭合，保持到结束。

深灰色影棚背景，均匀侧光照清上唇边缘、嘴角和下颌接缝，灰白色 3D 打印材质，微距，清晰。无切镜、无字幕。
不要：下巴大幅掉落、下半张脸张开、开口超过状态卡第3格、耳侧护板或颊板移动或消失、机位转到正侧面、嘴唇变形、噘嘴、圆口、舌头、牙齿、长时间张嘴不动。
```

### 验收标准

回片发我，我用同样的逐帧测量来判断：

1. 歌声期间下颌开合 **至少 7 次**。
2. 每一帧的开口都**不超过**状态卡第 3 格。
3. 耳侧护板、颊板全程存在，机位和首帧一致。
4. 按音轨对齐以后，**至少 70% 的开口起点**落在音节起点前后 0.15 秒（4 帧）以内。
5. 声音偏移只记录，不算失败。

### 停止条件

只要第 1 条或第 4 条没达标，就**不再用提示词去磨逐字口型**，改走确定性的路线：

- **首选：用实体机器人拍对口型的特写。** 下颌由人声实时驱动，这本来就是“实体演出”要的效果，口型也百分之百准确。AI 只负责全景、比例、场景和不对口型的镜头。
- **其次：剪辑上回避。** 对口型的正面特写减少到最少；演唱用中景、侧面、背面、手部和长音特写来表现。长音特写里持续张开是合理的，这条诊断片的问题在那里反而不是问题。

## 4. 对“实体演出测试版”流程的影响

**口型只阻塞一类镜头：** 需要逐字对口型的正面和四分之三侧脸特写，约占 12 组镜头的三分之一。

**现在就可以先做的，都不受影响：**
- 规格确认表，最要紧的是**实际身高**和**下颌能不能由音频驱动**；
- 实体机器人的照片；
- 定妆图和比例图（D1–D3）；
- 人声分轨（我用它来切片、测偏移、重算动作表）；
- 不对口型的组：冷开场 P0、间奏 P5、尾声 P10、收工 P11；
- 演唱组里的全景、手部、反应镜头。如果你愿意，我可以把演唱组拆成“对口型特写”和“不对口型”两部分，让后者先做。
